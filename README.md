# SpriteCut PRO (sprint-app)

App web para recortar spritesheets, animar clips e exportar ZIP / HTML animado limpo.

## Como usar

1. Abra `index.html` no navegador
2. Carregue a spritesheet
3. Detecte/ajuste a grade → Anime → Exporte ZIP ou HTML
